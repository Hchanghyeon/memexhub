# Notion ✅ (내보내기)

**결제**와 **건강 기록**을 Notion 데이터베이스로 복사할 수 있어요. Notion에서 계획하고 돌아보는 분들을 위한 기능이에요. 원본은 memexhub 기록이고, Notion에는 15분마다 사본이 가요.

## 설정

1. notion.so/my-integrations → **새 통합**(내부용) → 시크릿 복사
2. Notion에서 데이터베이스를 둘 페이지 → **⋯ → 연결 → 내 통합 추가**
3. memexhub 관리 화면 → 연결 → *Notion*: 페이지 링크와 시크릿(암호화 저장)
4. 기능 → **Notion**: 결제 또는 건강 켜기 → **Sync now** (또는 15분마다 자동)

그 페이지 아래에 **"memexhub · Payments"**(가맹점, 날짜·시각, 금액, 카드, 장소, 품목, 온라인, 종류)와 **"memexhub · Health"**(날짜, 걸음, 수면 시간, 안정 심박, 활동 kcal, 운동, 요약)를 만들어요.

## 동작

- **중복 없음**: 기록마다 Notion 페이지를 기억해서, 다시 보내도 새 기록만 만들고 바뀐 기록만 고쳐요(예: 나중에 결제 메일로 품목이 붙은 결제).
- Notion에서 고친 내용은 다시 읽어오지 않아요. 그 기록이 바뀌면 덮어써질 수 있어요.
- `api.notion.com`에만 연결하고, 속도 제한을 지켜요(초당 약 3건, 429면 기다림).
- Notion은 외부 서비스예요. **켠 종류만** 복사해요. 좌표는 보내지 않고 장소는 이름만 보내요.

## 나중에

볼트 자체를 Notion에 두는 것(저장소 어댑터)은 따로 계획해요. 마크다운 ↔ Notion 블록 변환은 손실이 있어서 별도 설계가 필요해요.
