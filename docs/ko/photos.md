# 사진 ✅

폰 사진 백업 폴더를 memexhub에 **읽기 전용**으로 붙이면, Claude가 그날 사진을 **작은 미리보기**로 보고 일지를 채워요. 사진은 바꾸거나 옮기지 않고, 미리보기도 어디에도 저장하지 않아요. 관리 화면 → **기능 → 사진**을 켜고 **연결 → 사진**에서 폴더를 골라요.

| 사진 | Claude가 하는 일 |
|---|---|
| 음식·음료 | `meal_add`로 식단 기록 (양이 애매하면 물어봄) |
| 영수증 | 그 시각 결제(`payments_day`)와 맞춰 가게·합계·품목을 알려 줌 (직접 결제를 기록하지는 않음) |
| 문서·필기·화이트보드·책 | 글로 옮겨 `wiki_save_source`로 원본 저장 |
| 스크린샷 | 무엇이었는지 한 줄 (남의 메시지는 옮기지 않음) |
| 장소·행사·풍경·산 물건·운동 | 일지 한 줄 |

**지키는 규칙:** 얼굴을 알아보거나 이름을 짐작하지 않아요(일정이나 주인 말로 알 때만). 카드·계좌·신분증 번호, 비밀번호, 인증번호는 옮기지 않고 "개인 정보라 건너뜀"으로 써요. 사진에 없는 건 지어내지 않아요.

## 붙이기

1. 폰 사진이 서버 폴더로 백업되게 해요. 예: **시놀로지 포토** 모바일 백업(`homes/<사용자>/Photos/MobileBackup`), Nextcloud 자동 업로드, Syncthing.
2. 그 폴더를 컨테이너에 읽기 전용으로 붙여요: `- /path/to/Photos/MobileBackup:/photos:ro` (허용 위치는 환경 변수 `PHOTO_ROOTS`, 기본 `/photos`)
3. 관리 화면 → 연결 → 사진 → **이 서버의 사진 폴더**, 폴더 `/photos`
4. 기능 → **사진** 켜기

- **찍은 시각**은 파일 수정 시각이에요. 폰 백업 앱들이 찍은 시각으로 맞춰 둬요.
- **미리보기**는 사진 앱이 이미 만든 썸네일(시놀로지 `@eaDir/…/SYNOPHOTO_THUMB_M.jpg`)을 쓰고, 없으면 1.5MB 이하 JPEG·PNG 원본을 써요. 썸네일 없는 HEIC는 목록에만 나와요(이미지 라이브러리를 넣지 않아서).
- 연속 촬영(3초 안)은 한 장만, 많으면 고르게 최대 24장까지 보여 줘요.

**아이폰 팁:** 아이폰은 앱이 뒤에서 마음대로 백업하지 못하게 해요. 단축어 자동화로 **충전기 연결 시 / 기상 알람을 멈출 때 → 앱 열기(Synology Photos)**를 걸어 두면 하루 두 번 올라가요. 밤 루틴은 어제와 오늘을 다시 보니까 늦게 올라온 사진도 다음 날 채워져요.

## 도구와 요약

- `photos_day(date?, from?, to?, kinds?, limit?)`: 그날(또는 시간대) 사진 목록과 미리보기 이미지
- `day_summary`: "📷 사진 28 · 스크린샷 4 · 동영상 2" 한 줄, 장면마다 그곳에서 찍은 장 수(📷 3)
