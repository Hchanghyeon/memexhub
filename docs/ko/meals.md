# 식단 ✅

Claude 앱에서 **음식 사진을 보내거나 먹은 걸 말하면**, Claude가 음식마다 양·칼로리·단백질·탄수화물·지방을 어림해서 기록해요. 관리 화면 → **기능 → 식단**을 켜면 써요.

```
나: (사진) 점심 이거 먹었어
Claude: 제육덮밥 1인분 약 850 kcal, 된장국 약 80 kcal로 기록할게요. 밥을 다 드셨나요?
```

- **어림값이에요.** 사진으로 보는 거라 ±20~30% 틀릴 수 있어요. 양을 같이 말하면("반 공기만") 정확해져요. 영양 성분표나 식당이 밝힌 값이면 `estimated: false`로 남겨요.
- **노트:** `meals/{year}-{month}.md` (기능 → 식단에서 경로를 바꿔요). 날짜마다 합계와 표 하나. 엔진이 매번 다시 그려요.
- **하루 요약:** `day_summary`에 "🍽 3번 · 1,850 kcal · 단백질 80g …"이 들어가고, 끼니는 그때 있던 **장면**(체류·결제)에 붙어요. 예: `12:20 📍 식당 · 💳 ₩9,000 · 🍽 점심 제육덮밥 850 kcal`.
- **한 주:** `week_summary`에 하루 평균 섭취와 기록한 날 수가 지난주와 같이 나와요.

| 도구 | 하는 일 |
|---|---|
| `meal_add(items, date?, time?, slot?, place?, note?, estimated?, replaces?)` | 끼니 기록. `replaces`로 앞 기록을 고쳐요 |
| `meal_day(date?)` | 그날 끼니(id 포함)와 합계 |
| `meal_cancel(id)` | 잘못 넣은 기록 취소 (이력은 남고 노트에서만 빠져요) |

Claude는 주인이 먹었다고 하지 않은 음식은 기록하지 않아요. 결제 기록만 보고 음식을 짐작하지 않아요.
