# Claude 연동

## 연결하기

1. 관리 화면 → `PUBLIC_URL/mcp` 복사
2. Claude 앱 → 설정 → 커넥터 → 사용자 지정 커넥터 추가 → 붙여 넣기
3. 브라우저에 memexhub 승인 화면이 열려요 → 관리자 로그인(+ 2단계 인증) → **허용**

뒤에서 일어나는 일 (OAuth 2.1):

```
Claude ──▶ /.well-known/…                 인증 방식 확인
Claude ──▶ POST /register                 redirect는 허용된 호스트(claude.ai, claude.com)의 https만
브라우저 ─▶ GET/POST /authorize           관리자 로그인 + 승인. PKCE S256 필수, redirect 정확히 일치
Claude ──▶ POST /token                    60초짜리 일회용 코드 + 검증값 → 액세스(1시간) + 리프레시 토큰
Claude ──▶ POST /mcp  (Bearer)            도구 호출마다. 리프레시는 조용히 회전
```

- 토큰은 **해시로만 저장하는 랜덤 문자열**이라, 관리 화면에서 끊으면 바로 무효가 돼요.
- 이미 바뀐 리프레시 토큰을 다시 쓰면 그 계열을 전부 폐기해요 (탈취 감지).
- IP 허용 목록을 켜면 `/mcp`는 Anthropic 서버에서만 받아서, 토큰이 새도 다른 곳에선 못 써요.
- 사용자가 토큰을 복사할 일은 없어요. 폰에도 아무것도 안 남아요.

## 계산은 엔진, 판단은 Claude

| 일 | 누가 |
|---|---|
| 결제·돈 노트, 합계, 표, 링크 점검, 목차, 결제 메일 맞추기 | 엔진 (정확, 토큰 0) |
| 어떤 체류를 일정으로 넣을지, 하루 한 줄 요약, 주간 관찰, 위키 페이지 | Claude |

루틴을 싸게 만드는 도구 📝:

- `day_summary(date)` — 체류, 결제, 교통, 건강, 메일 수를 한 번에 (큰 연간 노트를 안 열어도 돼요)
- `week_summary(week)` — 주간 숫자와 지난주 비교
- `hub_status()` ✅ — 연결 상태와 마지막 수신 (설정·비밀은 안 보여 줌)

## 루틴

Claude 예약 루틴은 지시를 볼트 노트에 두는 게 좋아요 ("`rules/nightly.md`를 읽고 코드 블록대로 해"). 그 노트를 **보호 경로**에 넣어 두면, 속은 Claude가 내일의 지시를 바꿔 쓸 수 없어요.

## 도구 설명 언어

모든 도구는 영어·한국어 설명을 같이 가져요. 관리 화면 → Claude 커넥터 → *도구 설명 언어*에서 `en`, `ko`, `both` 중 골라요.
