# 설정과 저장

## 환경 변수 (이것만)

| 변수 | 필수 | 뜻 |
|---|---|---|
| `MEMEXHUB_SECRET` | ✅ | 32자 이상. 저장하는 비밀값을 암호화하는 열쇠. `openssl rand -base64 48`로 만들고 비밀번호 관리자에 보관. 예시 같은 값은 거부해요 |
| `PUBLIC_URL` | ✅ | MCP 입구의 바깥 주소 (OAuth 발급자). `https://`만 (localhost만 http 허용) |
| `DATA_DIR` | ✅ | `memexhub.db`, 내장 볼트, 캐시, 백업 위치. 권한 700으로 만들어요 |
| `LISTEN` | | `split`(기본) 또는 `single` |
| `MCP_PORT` / `INGEST_PORT` / `ADMIN_PORT` / `SINGLE_PORT` | | 8787 / 8790 / 8791 / 8787 |
| `TZ` | | 시간대 |
| `VAULT_ROOTS` | | 관리 화면에서 "서버의 기존 폴더"로 고를 수 있는 기준 폴더 (기본 `/vaults`). 보안 경계예요 — 화면에서 아무 경로나 못 골라요 |
| `TRUSTED_PROXIES` | | 역방향 프록시의 IP 대역. 여기서 온 요청만 `X-Real-IP`를 믿어요 |

나머지(관리자 계정, 볼트 위치, 모듈, 연결, 토큰, 허용 목록, 도구 언어)는 전부 관리 화면에서 설정하고 DB에 저장해요.

## `DATA_DIR`

```
DATA_DIR/
├─ memexhub.db   SQLite (WAL), 권한 600
├─ vault/        내장 볼트 (골랐을 때)
├─ cache/        원격 볼트 캐시·검색 색인 (지워도 됨) 📝
└─ backups/      매일 암호화한 DB 백업 (최근 14개)
```

| 표 | 내용 | 비밀 처리 |
|---|---|---|
| `admins` | 관리자 | PBKDF2-SHA256(60만 회) 해시, TOTP 비밀은 암호화 |
| `admin_sessions` | 세션 | 세션 id는 해시, CSRF 토큰, 30분 무활동 만료 |
| `settings` | 비밀이 아닌 설정 | — |
| `connections` | 공급자 연결 | `secrets_enc`: AES-256-GCM, 용도별 HKDF 키, AAD = 연결 id. 어떤 API로도 돌려주지 않음 |
| `ingest_tokens` | 기기 토큰, 범위, 마지막 사용 | 해시만. 만들 때 한 번만 보여 줌 |
| `oauth_*` | 커넥터 등록, 일회용 코드, 토큰 | 해시만 |
| `events` | 추가만 하는 기록 | — |
| `cursors` | 어디까지 읽었나 | — |
| `audit` | 누가 무엇을 바꿨나 | 내용·비밀 없음 |

`MEMEXHUB_SECRET`을 잃어버리면 연결 비밀값만 못 읽어요. 그 계정들만 다시 연결하면 되고, 설정과 기록은 그대로예요.

## 볼트를 어디에

설치 마법사가 먼저 "지금 Obsidian을 어떻게 동기화하세요?"를 묻고 추천해요.

| 선택 | 언제 | 상태 |
|---|---|---|
| **이 서버에 새로 만들기** (추천) | 새로 시작, 동기화 안 씀 | ✅ 폴더 · Obsidian 동기화용 내장 WebDAV ✅ |
| 이 서버의 기존 폴더 | 볼트가 이미 서버에 있음 | ✅ (`VAULT_ROOTS` 아래만) |
| WebDAV | Nextcloud, NAS WebDAV, Remotely Save WebDAV | ✅ |
| S3 / R2 / MinIO | Remotely Save S3 | ✅ |
| Git | Obsidian Git | 📝 |

Obsidian Sync(공식)와 iCloud는 서버에서 읽을 API가 없어요. 위 방법 중 하나를 같이 써야 해요.

## 볼트 안전 규칙 (모든 저장소에 적용)

모듈은 `SafeVault`로만 볼트를 만져요.

- 경로 정규화. `..`, 절대 경로, NUL, 숨김 파일·폴더 거부. `.md` 노트만
- **보호 경로**(기본 `CLAUDE.md`, `AGENTS.md`, `_templates/**`, `.obsidian/**`, 여기에 루틴 규칙 노트를 더하세요)는 도구로 못 써요
- 읽기 전용 모드, 쓰기 크기 제한 (기본 512KB)
- 삭제 = `.trash/`로 이동 (목록에서는 숨김)
- 내용이 같으면 안 써요 (동기화가 쓸데없이 안 돌게)
- 모든 쓰기를 감사 기록 (경로, 크기, 해시 앞부분 — 내용은 남기지 않음)

## 내장 WebDAV (서버 볼트 동기화) ✅

볼트가 서버에 있으면(서버 내장·서버 폴더) memexhub가 WebDAV로 내보내서, 폰·PC의 Obsidian이 바로 동기화할 수 있어요. 서버를 하나 더 띄울 필요가 없어요.

1. 관리 화면 → Vault → **Sync with Obsidian on your devices** 켜기
2. Devices → 기기마다 범위 `dav` 토큰 만들기
3. Obsidian → **Remotely Save** 설치 → WebDAV: 주소 `https://<수집 주소>/dav/`, 아이디는 아무거나, 비밀번호는 기기 토큰

기본은 꺼짐 · 기기별 토큰으로 Basic 인증(기기를 잃어버리면 그 토큰만 끊기) · 속도 제한 · 볼트 밖으로 못 나감(`..`·심볼릭 링크 거부) · 지우면 `.trash`로(WebDAV에선 안 보임) · 파일 크기 제한(기본 50MB) · 응답은 샌드박스(`Content-Security-Policy: sandbox`) · 모든 쓰기를 내용 없이 감사 기록

## 변경 이력 ✅

서버 디스크의 볼트(내장·서버 폴더)는 memexhub 가 **모든 변경을 git 에 남겨요.**
- 저장소는 볼트 **옆**(`DATA_DIR/vault-history/<볼트>.git`)에 있어서 볼트 폴더에 `.git` 이 생기지 않고, 폰 동기화에도 영향이 없어요.
- **기록하는 것:**
  - memexhub 를 거친 쓰기는 누가 했는지(Claude, 관리자 …)와 함께 남아요.
  - memexhub 가 노트를 덮어쓰기 전에, 밖(Obsidian·서버)에서 고친 내용을 먼저 기록해요. 그래서 사람이 고친 판이 사라지지 않아요.
  - 그 밖의 바깥 변경은 10분마다 모아서 기록해요.
- **기록하지 않는 것:** `.obsidian/`, `.trash/`
- **보는 곳:** 관리 화면 **노트**에서 노트마다 *이전 판*을 보고 *되돌릴* 수 있어요. 되돌리기도 새 변경으로 남고, 쓰기 규칙이 그대로 적용돼요. Claude 는 `note_history` 로 이전 판을 읽을 수 있어요(읽기 전용).
- **켜기/끄기:** 볼트 → *모든 변경 기록*
- **백업:** 이력은 백업 파일에 들어가지 않아요. 남기려면 NAS 도구로 `DATA_DIR` 을 백업하세요.
- 서버 밖으로 나가는 건 없어요. 원격 git 저장소로 올리는 기능은 선택 사항으로 나중에 넣을 예정이에요.
- **쓸 수 있는 곳:** git 이 필요해요(Docker 이미지에 들어 있어요). Workers 와 원격 볼트에서는 못 써요.

## 백업 ✅

관리 화면 → **Backups**: 지금 암호화 백업 내려받기, 매일 자동 사본 보기(`DATA_DIR/backups`에 최근 14개), 복원(확인으로 `RESTORE` 입력). 백업에는 설정, 연결(비밀값은 암호화된 채로), 토큰(해시), 기록, 대기함, 활동 기록이 들어가요. **복원하려면 같은 `MEMEXHUB_SECRET`이 필요해요** — 백업과 따로 안전한 곳에 보관하세요. 볼트 노트는 들어가지 않아요. 볼트는 저장소나 동기화로 백업하세요.

관리 화면 → **Activity**에서 로그인, Claude·기기가 볼트에 쓴 기록, 설정·연결 변경을 볼 수 있어요. 내용이나 비밀값은 절대 남기지 않아요.
