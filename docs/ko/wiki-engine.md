# 위키 엔진

> 원본은 고치지 않는다. 위키 페이지는 LLM이 다듬는다. 목차·링크·규칙은 엔진이 정리한다.
> — LLM Wiki 패턴 (Andrej Karpathy)

## 용어

| 말 | 뜻 |
|---|---|
| 볼트 | Obsidian 폴더 전체. 내 노트, 자동 기록, 위키 층, 규칙 노트 |
| LLM Wiki | 목표. 좁게는 위키 층 — 원본 → LLM이 쓰는 페이지 → 목차와 로그 |
| 원본 | 고치지 않는 출처. 저장한 글, 그리고 **내 생활 기록도** 원본이 될 수 있어요 (주간 회고 → "내 소비 패턴" 페이지) |
| 엔진 | memexhub |

## 폴더가 아니라 역할 📝

| 역할 | 뜻 | Karpathy식 | PARA 예 |
|---|---|---|---|
| `sources` | 원본 | `raw/` | `Resources/Sources/` |
| `wiki` | LLM이 쓰는 페이지 | `wiki/` | `Resources/Wiki/` |
| `index` | 목차 방식 | `index.md` | 폴더 노트 |
| `log` | 위키 작업 로그 | `log.md` | `Resources/Wiki/log.md` |
| `daily` | 일지 | — | `Journal/YYYY-MM-DD` |
| `logs` | 자동 기록 노트 | — | `Journal/payments/{year}` |
| `rules` | 규칙 노트 (도구로 못 고침) | `CLAUDE.md` | `CLAUDE.md`, 루틴 규칙 |
| `archive`, `trash` | 보관, 휴지통 | — | `Archive/`, `.trash/` |

- 역할을 비우면 그 기능이 꺼져요.
- **프리셋**으로 한 번에 채워요: `llm-wiki`, `para`, `para-ko`, `zettelkasten`, `flat`.
- 빈 볼트면 프리셋대로 폴더와 규칙 노트를 깔아 주고, 기존 볼트면 엔진이 역할을 제안하고 사람이 확정해요.
- 이 설정을 볼트 안의 규칙 노트(보호 경로)로 내보내서 Claude도 같은 규칙을 읽게 할 수 있어요.

## wiki 모듈 📝

| 도구 | 하는 일 | 왜 엔진이 |
|---|---|---|
| `wiki_lint` | 깨진 링크, 고아 노트, 목차 누락, 큰 페이지, 등록 안 된 태그, 프론트매터 누락, 근거 링크 없는 위키 주장 | 정답이 있는 검사, 토큰 0 |
| `wiki_save_source` | 원본을 `sources`에 그대로 저장, 프론트매터만 붙임 | "원본은 안 고친다"를 보장 |
| `wiki_index` | 목차에 한 줄 추가·정렬, 길어지면 쪼개기 | 기계적인 정리 |
| `wiki_backlinks(path)` | 이 노트를 가리키는 노트 | Claude가 맥락을 찾을 때 |
| `wiki_log` | 위키 로그에 한 줄 추가 | 추가만 하는 규칙 |

점검 규칙은 하나씩 켜고 꺼요. 내 볼트의 규칙(필수 프론트매터, 등록된 태그만, 페이지 크기, 목차 길이)은 그중 몇 개를 켠 것일 뿐이에요.

요약, 개념 페이지, 모순 판단은 Claude 몫이에요: "수집해줘", "위키에서 찾아줘", "점검해줘".
