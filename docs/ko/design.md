# UI/UX 디자인

관리 화면은 가끔, 급하게 써요. 처음에 한 번 설정하고, 연결을 고치고, 토큰을 끊을 때요. 그래서 **생각하지 않고 끝내는 것**을 목표로 해요.

## 원칙

1. **편리함이 먼저.** 모든 화면이 "다음에 뭘 하면 되지?"에 답해요. 기본값은 추천값이고, 추천하는 선택지는 맨 위에 "(추천)"으로 둬요.
2. **화면 하나에 할 일 하나.** 설치 마법사는 한 줄로 이어져요: 질문 하나, 행동 하나, 그리고 *다음*. 아직 필요 없는 설정은 안 보여요.
3. **쉬운 말로.** 라벨은 구현이 아니라 결과를 말해요 ("/mcp는 Anthropic 서버에서만 받기"). 도움말은 한 문장.
4. **경고 대신 안전한 구조.** 위험한 동작은 숨기거나 한 단계를 더 거치게 하고, 비밀값은 복사 버튼과 함께 "다시 안 보여요"를 분명히 하고 한 번만 보여 줘요.
5. **결과를 항상 알려 줘요.** 저장하면 짧은 완료 메시지, 시험이 실패하면 무엇이 잘못됐고 어떻게 고치는지.
6. **빠르고 가볍게.** 서버에서 그린 HTML, 프론트엔드 빌드 없음, 가능하면 자바스크립트 없이도 동작, 폰에서도 읽기 편하게.
7. **접근성.** 진짜 `<label>`, 키보드로 다 닿고, 포커스가 보이고, 대비 4.5:1 이상, 색만으로 뜻을 전하지 않기 (글자나 아이콘을 같이).
8. **두 언어.** 사용자에게 보이는 글은 전부 영어와 한국어로.

## 시각 스타일

- **깔끔하고 조용하게.** 여백 넉넉히, 한 열, 최대 폭 약 720px.
- **색은 적게.** 기본은 무채색(회색 계열), **강조색 하나**는 주요 버튼에만, 빨강은 오류와 위험한 동작에만, 초록은 "연결됨/정상"에만. 그라데이션이나 장식용 색은 쓰지 않아요.
- **글꼴은 시스템 글꼴 하나**, 굵기 두 가지, 크기 세 가지(제목, 본문, 작은 글씨).
- **단순한 구성 요소**: 기본·보조·위험 버튼, 1px 테두리 카드, 단순한 표. 뜻을 더하지 않는 아이콘은 안 써요.
- **같은 말은 같은 동사로**: *연결*, *연결 시험*, *저장*, *끊기*, *토큰 만들기*: 어디서든 같은 행동엔 같은 말.

## 디자인 토큰

색 · 글자 · 간격 · 모서리 · 움직임은 [`design/tokens.json`](../../design/tokens.json) 한 파일에만 있어요. 안드로이드 앱과 함께 써요. `npm run tokens` 가 `web/src/tokens.css`(`--mx-*` 변수)와 앱의 `Tokens.kt` 를 만들고, CI 가 `npm run tokens:check` 로 어긋나면 막아요. 방향: 깔끔하게, 큰 숫자 먼저, 글자는 로고의 먹색, 고유 색은 인덱스 블루 하나. 자세히는 [design/README.md](../../design/README.md).

## 문구 점검

- 배경 설명이 아니라 행동이나 결과로 시작해요.
- 쉬운 말이 있으면 전문 용어를 안 써요 ("인증" 대신 "로그인").
- 오류: 무슨 일이 있었나 + 어떻게 하면 되나 ("설치 코드가 틀렸어요. 서버 로그에서 복사해 다시 넣어 주세요.").
- 느낌표와 탓하는 말은 쓰지 않아요.
