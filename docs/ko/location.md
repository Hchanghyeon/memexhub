# 위치 ✅

어디에 있었는지를 **체류**("10:00–10:30 · 샘플카페")로 보여줘요. 결제 장소 이름도 여기서 와요. 좌표는 DB나 내 위치 서버에만 있고, **볼트에는 이름만** 들어가요(좌표·번지 없음).

## 출처 (연결)

| 공급자 | 무엇 | 설정 |
|---|---|---|
| **Dawarich** | 내가 띄운 Dawarich 서버 | 연결 → Dawarich: 주소 + API 키. Dawarich에 그려 둔 **Areas**("집", "회사")가 장소 이름이 돼요. |
| **OwnTracks** | OwnTracks 앱(또는 같은 형식)이 memexhub로 위치를 보냄 | 연결 → OwnTracks. 장소는 한 줄에 하나씩 `이름, 위도, 경도, 반경(m)`. 앱: 모드 *HTTP*, 주소 `https://<수집 주소>/ingest/owntracks`, 헤더 `X-Ingest-Token`에 범위 `location` 기기 토큰. 점은 `keepDays`(기본 400일) 동안만 보관해요. |
| **Nominatim** (지명) | OpenStreetMap 역지오코딩 | 연결 → Nominatim. 공개 서버는 초당 1건, 연락처를 적어 주세요. 결과는 캐시해요. 내 Nominatim 주소로 바꿀 수도 있어요. |

관리 화면 → 기능 → **Location**: 쓸 위치 출처와 지명 변환기, **비공개 장소**(어디에도 안 씀 — 예: "집"), 언어.

## 이름 붙이는 순서

1. 등록된 장소 안이면 그 이름 (비공개 장소면 아무것도 안 씀)
2. 역·정류장이면 그 이름
3. 아니면 동네(시·구·동), 번지는 지워요

## 체류

반경 **150m** 안에 **15분 이상** 있으면 체류, 200m 안의 이웃 체류는 합치고(GPS 흔들림), 오차 1km 넘는 점은 버려요. 숫자는 설정(`location.stay`)이에요.

## 도구

| 도구 | 하는 일 |
|---|---|
| `location_day(date)` | 그날 체류(이름·시간), 이동 거리, (Dawarich) 앱이 추정한 방문 — 체류와 안 맞으면 표시 |
