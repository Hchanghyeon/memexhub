# 집 (홈 어시스턴트)

memexhub가 홈 어시스턴트를 읽어서(읽기 전용) Claude가 지금 집 상태와 그날 있었던 일을 볼 수 있어요. 서비스는 절대 호출하지 않아요. memexhub로는 조명·잠금·스위치를 못 바꿔요.

1. 홈 어시스턴트: 내 프로필 → 보안 → **장기 액세스 토큰** 만들기
2. 관리 화면 → 연결 → **홈 어시스턴트**: 주소(예: `http://192.168.0.10:8123`), 토큰, "집 네트워크" 체크
3. 선택: **하루 요약에 넣을 엔티티**를 쉼표로 — 예: `person.me, binary_sensor.front_door`. 그 기록이 `day_summary`에 들어가요.

도구: `home_states`(지금 상태, 글자로 거르기), `home_day`(그날 로그북, 엔티티 하나만도 가능).
